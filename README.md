🌸 Flower Ecommerce Website (Django)

A full-featured flower ecommerce web application built using Python and Django, allowing users to browse flowers, add items to cart, manage favorites, and proceed to checkout with multiple payment options.

✨ Features
🌼 Product listing for flowers with images and details
🛒 Add to Cart functionality with quantity management
❤️ Wishlist / Favorites system
💳 Checkout system (Payment integration pending)
PayPal (planned)
Credit/Debit Card (planned)
Cash on Delivery (COD)
📦 Order summary page
🔐 User authentication (login/register/logout)
📱 Responsive UI using HTML, CSS, Bootstrap
🛠️ Tech Stack
Backend: Python, Django
Frontend: HTML, CSS, Bootstrap, JavaScript
Database: SQLite / MySQL (based on configuration)
Payment Gateway: ( integrated – planned for PayPal/Card API)
